# Roadmap

This roadmap describes current product direction, not commitments or delivery
dates.

## Next

- Publish worked, sanitized examples that show a complete approved workflow.
- Add installation validation and clearer troubleshooting guidance.
- Improve starter-pack selection guidance and collect requests for new project
  classes.
- Document practical task-management integration patterns for Codex users.

## Later

- Expand the catalog from feedback on real project classes and constraints.
- Add compatibility and regression checks for the installable skills.
- Publish guidance for maintaining and versioning organization-specific packs.

## Help shape it

Open an **Onboarding feedback** issue or GitHub Discussion describing your
project class, desired outcome, and what a good pack would need to handle.
Never include credentials or private project documents.
