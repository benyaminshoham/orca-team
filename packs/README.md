# Knowledge packs

`template/` is a scaffold, not a second pack type. It mirrors the required
universal pack shape. Copy it only as the beginning of the `build-agent-team`
workflow; do not run a project from the unfilled scaffold.

Every finished pack is reusable within its declared applicability and can be
bound to concrete project documents at execution time. Packs should be
generated only after the skill's intake, team approval, and source approval
gates. See
`../docs/pack-catalog.md` for the included common-project packs.
